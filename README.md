# Registro de Notas

Aplicación desarrollada en Python para registrar notas de estudiantes,
calcular el promedio y determinar si el estudiante aprueba o reprueba.

## Funcionalidades

- Registrar notas entre 0 y 5.
- Consultar el promedio de las notas registradas.
- Determinar si el promedio es aprobado o reprobado.
- Menú interactivo mediante un ciclo `while`.

## Tecnologías utilizadas

- Python 3
- Git
- GitHub

## Estructuras y conceptos utilizados

- Listas
- Funciones
- Ciclo `while`
- Condicionales `if`, `elif` y `else`
- Validación de datos
